# Input Models

Each folder holds the input model of one application, which Aletheia analyzes instead of a Blueprint application:

```zsh
./bin/aletheia --input input-models/postnotification
```

See the documentation for how to run, combine and write input models:

- [Registering an Application without Blueprint](https://aletheia-microservices.github.io/aletheia/3-usage/without-blueprint.html)
- [Writing Input Models](https://aletheia-microservices.github.io/aletheia/4-formats/writing-input-models.html)
